# Security reports

Please send suspected vulnerabilities to **support@swiftbyte.app** with the subject “Halls security report.” Include the affected platform/version, reproduction steps, and impact. Do not post exploitable details, credentials, private user information, or signing material in public issues.

Use your own Firebase and Google Maps projects for development. The repository intentionally excludes production service configuration and signing credentials. Report an accidentally committed credential privately.

This project does not promise a fixed security response or support window.
